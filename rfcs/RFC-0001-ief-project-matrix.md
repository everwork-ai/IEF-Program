# RFC-0001: IEF Project Matrix

## Summary

IEF is organized into Program, Governance, Knowledge, Operations, Protocol, Runners, and Adapters.

## Motivation

Enterprise AI workers need a clear separation of concerns: governance rules, knowledge memory, task operations, communication protocol, concrete runners, and host adapters.
